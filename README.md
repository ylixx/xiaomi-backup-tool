# 小米 USB 一键换机 / 数据备份还原工具

通过 USB 数据线（adb）把小米手机的 **照片 / 音频 / 视频 / 文档 / 联系人短信 / 应用数据**
一键备份到电脑，并可一键还原到新手机（换机）。全程带 **SHA256 完整性校验、
断点续传、失败自动重试、设备掉线自动恢复**，大数据量下不卡死、不崩溃。

> 技术栈：Python 3.10+ / PySide6 (Qt6) / adb（自动定位，无需手动安装）/ QThread 式后台线程池

---

## 1. 环境准备

### 1.1 电脑端

```bash
# Python 3.10 或更高
python -m pip install -r requirements.txt
```

**无需手动安装 adb**：程序按以下顺序自动定位 adb（满足验收 A1）：

1. 程序目录下的 `platform-tools/adb(.exe)`（可直接把官方 platform-tools 放进来）
2. 环境变量 `XIAOMI_BACKUP_ADB` 指向的 adb
3. 系统 PATH 中的 `adb`
4. Windows 常见安装位置（`%LOCALAPPDATA%\Android\Sdk\platform-tools` 等）

### 1.2 小米手机开启 USB 调试（MIUI / HyperOS）

1. **设置 → 我的设备 → 全部参数与信息**，连续点击「OS 版本」7 次 → 开启开发者模式
2. **设置 → 更多设置 → 开发者选项**，打开：
   - ✅ **USB 调试**（必须）
   - ✅ **USB 调试（安全设置）**（部分机型需要，需登录小米账号）
   - ✅ **USB 安装**（应用数据备份可能需要）
3. 用数据线连接电脑，手机通知栏把 USB 用途改为 **「传输文件 (MTP)」**
4. **首次连接**手机会弹出「允许 USB 调试吗？」→ 勾选 **「始终允许」** 并确认
   （未授权时程序会显示黄色警示并给出本指引，见 A3）
5. 建议：**设置 → 息屏与锁屏 → 充电时屏幕不休眠**；
   小米部分机型息屏后会挂起 USB 传输（见 G2 提示）

> HyperOS / MIUI 额外限制：
> - 需要登录小米账号才能开启「USB 调试（安全设置）」
> - 系统目录（`/data/data`）未 root 不可读，应用私有数据无法完整导出（见第 6 节）
> - 若 `adb devices` 显示 `unauthorized`：重新插拔并在手机上点「允许」
> - 若始终无法连接：更换数据线（需支持数据传输）、更换 USB 口、关闭「MIUI 优化」后重启

## 3. 功能说明

### 3.1 备份（手机 → 电脑）

- **分类勾选**：图片（DCIM/Pictures/微信QQ图片）、音频、视频、文档、
  联系人/短信/通话记录、应用数据；支持全选/全不选
- **自定义目录**：手动填手机端路径（如 `/sdcard/MyFolder`）
- **备份前预检**：扫描生成清单（文件数 / 总大小），**目标盘空间不足直接拦截**（B3）
- **目录结构**（B4）：

```
Backup_20250101_120000/
├── photos/            # 按手机端相对路径完整保留层级
├── audio/
├── video/
├── docs/
├── contacts/          # 可选，文本导出
├── appdata/           # 可选，app_backup.ab
├── manifest.json      # 每文件：源路径/目标路径/大小/sha256/状态
├── manifest.json.bak  # 上一份清单备份
└── backup_info.json   # 设备信息 / 选项 / 时间
```

- **断点续传（C1/C4）**：勾选「继续之前的备份」并选择已有 `Backup_` 目录；
  已完成且大小一致的文件自动跳过，不重复传输
- **增量备份（省空间）**：勾选「增量备份」并选择基准备份目录（即上一次生成的
  `Backup_` 目录）；程序会对比基准备份清单，**仅传输变更 / 新增的文件**，
  未变化的文件直接复用、不重写本地文件。安全机制：跳过前先校验本地备份文件的
  sha256，若基准备份已损坏则强制重传，绝不基于脏数据跳过；手机端已删除的文件
  会在清单中标记为 `removed` 并保留备份数据（不参与还原）。适合定期重复备份以
  大幅节省时间与磁盘空间。
- **文档按类型过滤 + 深度扫描（防遗漏）**：「文档」类别默认按类型只收
  Office（doc/docx/xls/xlsx/ppt/pptx 等）/ PDF / 电子发票(OFD) / 文本 / WPS /
  电子书等，不会把照片视频一并打包；勾选「**深度扫描整机文档**」后会遍历整个手机
  存储（`/sdcard` 内部存储 + `/sdcard1` 外置 SD），散落在微信 / QQ / 网盘 / 各类 App
  任意目录里的文档都能找回，绝不遗漏。手机端无权限的 App 私有目录（`/sdcard/Android/data`）
  仍无法读取（需 root）。发票截图类图片请用「图片」类别备份。
- **暂停 / 继续 / 取消**：暂停停在安全断点（1MB 块边界），取消后已传文件状态正确落盘
- **进度**：总进度 + 当前文件进度 + 速度 + ETA，实时刷新且 UI 不阻塞（B5/F2）
- **文件名**：中文 / 空格 / 特殊字符原样保留，照片 EXIF 不被修改（B9）

### 3.2 还原 / 换机（电脑 → 手机）

- 选择备份目录 → **读取清单预览**（类别 / 文件数 / 大小，D1）
- **还原前检查手机剩余空间**，不足则拦截（D2）
- 还原到手机原始路径，或指定自定义前缀（如 `/sdcard/Restored`）
- 默认跳过设备端已存在且大小一致的文件（断点续传，D4），可勾选「强制覆盖」
- 还原后 **抽样校验**（含大文件）大小/哈希并输出结果（D5）
- 可选 `adb restore` 还原应用数据（需在手机端确认）

### 3.3 校验（E1/E2/E3）

- 「校验备份完整性」：全量比对大小 + SHA256，输出成功/失败清单
- `manifest.json` 丢失/损坏：「重建清单」从目录扫描恢复（降级处理，哈希后补）
- 校验发现不一致：「重传不一致文件」自动修复

### 3.4 可靠性设计（对应验收 C/F/G）

| 特性 | 实现 |
|---|---|
| 断点续传 | manifest 逐文件状态 + 大文件 1MB 对齐分块（`exec-out/in + dd`）可从块边界继续 |
| 完整性校验 | 每文件传输后计算 SHA256 写入 manifest；可选与手机端 `sha256sum` 双向比对 |
| 失败重试 | 指数退避最多 3 次（1s/2s/4s + 抖动），日志可见重试记录（C3） |
| 设备掉线 | 轮询检测 → 任务自动暂停并提示；重新插线后自动从断点继续，掉线不计入重试次数（C2/A4） |
| 防卡死 | IO 全在后台线程；线程池并发上限 4（默认 3，F3）；日志/进度 100ms 节流合并（F6） |
| 内存安全 | 全部流式读写（1MB 块），2GB+ 单文件不进内存（F4）；目录遍历流式分批（F5） |
| 空间预检 | 备份前查电脑目标盘、还原前查手机剩余空间 |
| 异常友好 | adb 超时/权限拒绝/文件占用/空间不足等统一翻译为中文提示，不抛裸异常（G1） |
| 限速 | 可选限速（MB/s），避免占满带宽 |

## 5. 已知限制（不虚假承诺）

1. **未 root 时应用私有数据（`/data/data`）无法完整导出**。
   `adb backup` 只能备份应用「允许备份」的数据，且需在手机端确认；
   部分应用（尤其微信、银行类）会直接排除。
   - **微信聊天记录**：请使用微信自带「设置 → 聊天 → 聊天记录迁移与备份」，
     或换机助手的「微信专项迁移」，本工具不会也无法绕过其加密存储。
2. 联系人/短信/通话记录通过 `content` 查询导出，**部分 MIUI/HyperOS 版本会拒绝访问**，
   导出失败仅告警不影响其它类别；重要数据请先用系统云同步。
3. `adb backup` 生成的 `.ab` 还原时需要手机端点击确认；不同 Android 版本对
   `adb backup` 的支持正在收紧（Android 12+ 部分机型已不支持）。
4. 小米部分机型**息屏后挂起 USB**：长任务请保持屏幕常亮（程序会在掉线时自动提示）。
5. 单文件 2GB+ 使用分块流式传输，速度略低于 `adb pull` 但内存恒定、可续传。
6. 本工具只操作 adb 授权范围内（外部存储）的数据，不做任何绕过系统限制的操作。
